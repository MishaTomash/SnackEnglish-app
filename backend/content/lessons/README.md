# Правила генерації JSON-контенту для уроків

При створенні тестових питань (у блоках `reading`, `test` чи інших), де є масив `options`, **ЗАБОРОНЕНО** використовувати `correctAnswerIndex`.

Замість цього завжди використовуйте поле `correctAnswer` (рядок), яке має **абсолютно точно збігатися** (включаючи регістр і пробіли) з одним із варіантів у масиві `options`.

## ✅ Правильний формат:

```json
{
  "question": "Which verb form is correct?",
  "options": ["go", "goes", "went", "gone"],
  "correctAnswer": "goes"
}
```
