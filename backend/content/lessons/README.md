Загальні технічні вимоги

Файли мають бути валідним JSON (без висячих ком, ключі та рядки строго в подвійних лапках "").

Уникайте перенесень рядків \n всередині значень, якщо це не передбачено логікою.

Усі індекси правильних відповідей (correctAnswer) починаються з 0.

Grammar (Граматика)

Для акцентування уваги на граматичній конструкції використовуйте обгортання слова чи фрази подвійними зірочками: **слово**. Застосунок автоматично зробить їх жирними та виділить фірмовим кольором.

Підсвітку потрібно застосовувати симетрично: як в англійському прикладі (en), так і в українському перекладі (ua).

Приклад: "en": "She **works** in a bank.", "ua": "Вона **працює** в банку."

Video (Відео — ОПЦІЙНИЙ КРОК)

Цей крок не є обов'язковим. Робіть його лише для тем, де аудіо-візуальне пояснення (напр. різниця між артиклями a/an) дійсно потрібне.

Якщо відео для юніту немає — просто не додавайте ключ video до об'єкта steps. Застосунок автоматично перерахує кроки, і таймлайн буде коректним.

Якщо ключ video додається, він обов'язково повинен містити url (посилання на YouTube) та caption (короткий текст-підказку, специфічну саме для цього відео, яка пояснює користувачу, на що звернути увагу).

Reading (Читання)

Текст у полі text обов'язково має бути розділений коректними розділовими знаками (крапки ., знаки питання ?, знаки оклику !).

Застосунок розбиває цей текст на масив речень для блоку розпізнавання голосу (читання вголос).

Speaking (Говоріння)

Перша репліка або цільове речення використовується для еталона розпізнавання голосу. Уникайте занадто довгих речень.

Vocabulary (Словник)

Поле transcription записуйте у квадратних дужках: "[weɪk ʌp]".

exampleSentence та exampleTranslation є обов'язковими для контекстного вивчення.

Test (Тестування)

У масиві options має бути від 2 до 4 варіантів відповіді.

Поле explanation є обов'язковим (показується при помилці).
